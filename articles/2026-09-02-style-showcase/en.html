This article isn't really about anything — it exists so that every element the article template supports shows up somewhere on one page. If you're writing a new article and wondering "does this look right?", check here first before publishing.

Basic inline formatting: bold text, italic text, and inline code all sit directly inside a paragraph like this one, no special markup needed beyond the tag itself.

A level-2 heading

Use <h2> for the main sections of an article — this is the size Japanese Grammar uses for "The particle is the grammar," for example.

A level-3 heading

Use <h3> for a sub-point inside a section — smaller than <h2>, still bold, less top margin.

Lists

An unordered list:

  • First point, no particular order
  • Second point
  • Third point, with inline code inside a list item

An ordered list:

  1. Do this first
  2. Then this
  3. Finally, this

Blockquote

A blockquote is for quoting someone or something external — it gets a left border and muted color, not italics, so it doesn't get confused with <em>.

A code block

For multi-line code or preformatted text, use <pre><code>:

function greet(name) {
  return "Hello, " + name + "!";
}
